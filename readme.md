**WP Bulk Pages Generator** is a powerful, user-friendly WordPress plugin that lets you create hundreds of pages, posts, or custom post types in just a few clicks. Unlike other tools that only create empty titles, our plugin allows you to **add unique content and full block markup** for every single entry as you build them.

---

## 🔝 Why Choose WP Bulk Content Creator?

- **SEO Ready**: Build content silos and site structures in minutes to boost your search engine discoverability.
- **Bulk Content & Blocks**: Paste unique text, HTML, or **Gutenberg Block Markup** (like headlines, images, and columns) directly into each row.
- **Dynamic Post Type Support**: Automatically detects every public post type on your site (Posts, Pages, Products, Portfolio, etc.).
- **Smart Hierarchy**: Easily select parent pages with a hierarchical dropdown that respects your site's structure.
- **Geist Premium UI**: A beautiful, minimalist interface designed for speed and clarity.
- **Bulk Removal**: Select all or specific rows to delete them instantly before you hit create.

---

## 🛠️ How It Works (Simple Steps)

1. **Choose Your Type**: Select if you want to create Posts, Pages, or a Custom Post Type.
2. **Add Rows**: Enter the number of items you want and click **Generate List**.
3. **Customize Everything**: Fill out the Titles, Slugs, and **Content** for each item.
4. **Hit Create**: Click **Create All Pages** and watch the real-time progress bar do the magic!

## � Installation

1. Download the plugin folder.
2. Upload it to your `/wp-content/plugins/` directory.
3. Activate it via the **Plugins** menu.
4. Start creating via the **"Bulk Pages"** menu in your sidebar!
